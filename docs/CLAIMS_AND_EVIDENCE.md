# 主张与证据门

## 核心主张

病理—通路 OT 结构承载可检验的预后语义；将运输代价推向训练折估计的高危/低危锚点并重新求解 OT，会产生可靠、可泛化的方向性风险响应。

## 证明链

| 子命题 | 必要证据 | 失败意味着什么 |
|---|---|---|
| 响应方向正确 | 持出患者的方向一致率及置信区间 | 锚点方向没有稳定进入风险输出 |
| 响应来自重运输 | fixed-coupling 后响应显著衰减；计划 TV 非零且边际误差合格 | 风险变化可能绕过运输计划 |
| 响应具有剂量结构 | 预注册 alpha 路径上的患者级单调率和曲线 | 端点结果可能只是偶然扰动 |
| 响应具有特异性 | 置乱参考、噪声锚点、stage jitter、可行计划置乱对照 | 任意扰动都能制造同类响应 |
| 响应可泛化 | 锁定阈值后跨 fold、跨癌种复现；报告异质性 | 结论只适用于单折或单队列 |
| 不牺牲预测有效性 | 同 split 的 2×2 消融、强基线、独立外层测试 | 机制响应可能以明显预测退化为代价 |

## 预注册通过线

这些数值是实验前的决策规则，不是当前结果：

- 方向一致率 `DCR > 0.55`，且主要汇总的 95% CI 下界高于 `0.50`。
- 剂量单调率 `DMR >= 0.70`。
- 平均计划总变差 `Plan TV >= 0.02`，每个重求解计划的最大边际误差 `< 1e-3`。
- fixed-coupling 相对完整重求解至少削弱 50% 的方向响应。
- 置乱/噪声对照向机会水平回落；高低锚点交换时响应方向反转。
- 完整方法相对 IPCW-only 的预测非劣界为 C-index 差值 `-0.01`，并报告逐折差值和置信区间。

若数据规模使某个置信区间门无法稳定估计，必须在看正式测试结果前修改协议并留痕，不能事后调阈值。
