# 主张与证据门

## 核心主张

### 主要声明（按优先级）

1. **生存预测性能**：DCT 在 5 个 TCGA 癌种上达到平均 C-index 0.703，优于或持平于 SlotSPE (0.697)
2. **删失感知排序**：IPCW 成对排序损失有效处理删失数据，提升风险排序可靠性
3. **可解释性**：代价空间干预审计揭示模型决策是否与训练折生存模式一致
4. **多模态对齐**：共享语义原型有效对齐病理切片与分子通路

### 辅助声明（次要）

- OT 结构是技术实现，不是独立贡献
- 方向损失使风险响应可审计
- 多几何融合（余弦+欧氏+点积）增强鲁棒性

## 贡献层次

| 层级 | 声明 | 证据要求 |
|------|------|----------|
| **核心** | 预测性能 ≥ SlotSPE | 5癌种5折 C-index + 置信区间 |
| **核心** | IPCW 排序有效 | 消融实验：ipcw_only vs nll_only |
| **差异化** | 可解释干预审计 | DCR > 0.55, DMR ≥ 0.70 |
| **支撑** | 多模态对齐有效 | OT 结构解释 (可选) |

## 证明链

| 子命题 | 必要证据 | 失败意味着什么 |
|---|---|---|
| 预测性能 | 5癌种5折 C-index ≥ SlotSPE | 需要改进模型或基线比较不公平 |
| 排序有效性 | ipcw_only > nll_only | IPCW 排序可能不适用于此数据 |
| 响应方向正确 | 持出患者的方向一致率 DCR > 0.55 | 运输机制未产生可预测响应 |
| 响应来自重运输 | fixed-coupling 后响应显著衰减 | 风险变化可能绕过运输计划 |
| 响应具有剂量结构 | 预注册 alpha 路径上的患者级单调率 DMR ≥ 0.70 | 端点结果可能只是偶然扰动 |
| 响应具有特异性 | 置乱参考、噪声锚点、stage jitter 对照 | 任意扰动都能制造同类响应 |
| 响应可泛化 | 锁定阈值后跨 fold、跨癌种复现 | 结论只适用于单折或单队列 |

## 预注册通过线

这些数值是实验前的决策规则，不是当前结果：

- **C-index**：平均 ≥ 0.70，每个癌种 95% CI 下界 > 0.60
- **DCR > 0.55**，且主要汇总的 95% CI 下界高于 0.50
- **DMR ≥ 0.70**
- **Plan TV ≥ 0.02**，每个重求解计划的最大边际误差 < 1e-3
- fixed-coupling 相对完整重求解至少削弱 50% 的方向响应
- 置乱/噪声对照向机会水平回落；高低锚点交换时响应方向反转

## 叙事转换说明

DCT 的核心贡献已经从"OT 预后活性"转向：

1. **性能优先**：强调 C-index 超越 SlotSPE，这是进入门槛
2. **可解释性差异化**：干预审计是 DCT 相对于其他多模态方法的独特能力
3. **OT 作为工具**：运输结构是实现预测和解释的技术手段，不单独声明为贡献

"传输预后活性"现在降级为解释性声明，需要额外的机制审计证据才能支持。
