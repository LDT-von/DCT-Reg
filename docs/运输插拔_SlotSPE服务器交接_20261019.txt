宿主若以后换修正版，应单独冻结版本、重新跑三臂，不能换入旧原版分数。
此为“原版模型在统一协议下比较”，不声称复现官方原训练流程。
总目标=宿主主NLL/批内患者数 + 宿主全部auxiliary；lambda_recon_loss=0.01、alpha_surv=0.5。
保留两单模态decoder NLL、组学自重构、跨模态重构和WSI重构；不加DCT目标。

4. 服务器执行
解压到一个新目录，不覆盖现有仓库。进入slotspe_transport_task_20261019。
使用已有具备torch、einops、numpy、pandas、scikit-survival的环境，不静默安装/升级。
原型组件导入需einops支持pack/unpack。本SlotSPE对比不需要POT。
设置真实路径（features根目录内应有临床wsi名称对应的.pt特征，RNA必须真实存在）：
  export OT_METADATA_ROOT=/实际/dataset_csv
  export OT_FEATURES_ROOT=/实际/UNI2-h-pt
规划（不读取患者、不创建结果目录）：
  python -B scripts/run_slotspe_transport_compare.py --config configs/slotspe_transport_compare.json --output /新路径/OT-03_slotspe_fold0_seed3
先由服务器AI检查可用资源、数据路径及已有任务；不得抢占正在运行的其他任务。
建议先复制配置为独立smoke配置，只改epochs=1、patches=256、eval_repeats=2，用独立smoke输出检查数据闭环。
smoke完成并通过验收后再执行原配置。smoke结果不并入正式性能表。
正式执行（此命令才准备患者数据并训练三臂）：
  python -B -u scripts/run_slotspe_transport_compare.py --config configs/slotspe_transport_compare.json --output /新路径/OT-03_slotspe_fold0_seed3 --run
结果验收（只读已有结果，不训练/不推理）：
  python -B scripts/audit_slotspe_transport_compare.py /新路径/OT-03_slotspe_fold0_seed3
执行失败返回非零并保存status=failed；保留失败目录，改用新目录，不能用旧状态冒充完成。
配置若不符合实际输入宽度，先核对特征版本；记录更改，三臂统一，不静默降预算。

6. 如何回答运输比普通混合多解决什么
固定边际a,b时Independent=a b^T，给每个槽同一份对侧加权均值；OT允许不同槽接收不同的对侧组合，
在相同信息预算下保留成对关系。阶段与几何直接平均，不增加DCT事件读取器。
只优于native：支持增加信息交换有用，不能归因运输匹配。
稳定优于independent且同权重去耦合有影响：支持配对结构有贡献，仍不能证明真实生物对应或OT优于注意力。
分开训练的两臂边际参数会分化；同checkpoint独立混合才固定权重与边际来检查关系依赖。
Independent虽实例化相同参数，平衡模式的成对成本网络没有有效梯度通路；不能称有效容量完全相同。
首组后才考虑同协议五折/多种子和容量相称注意力对照。无稳定收益就报告不足，不扩写通用增益。

7. 六宿主边界（本包只执行SlotSPE）
SlotSPE：已有槽→运输→原cross_attention；self/单模态decoder/重构继续用原槽。
SurvPath：已编码omics-first拼接token→运输→原cross_attender；长token原型汇总后恢复长度。
PIBD：PIB选token后、PID前；保留PoE与原目标。
MMP：只支持multimodal coattn，投影后identity入口；拒绝已有OT的coattn_mot。
LD-CVAE：只支持Robust_MCAT的coattn，组学真实/生成选择之后q=omics,k=v=WSI；不覆盖Robust_SurvPath。
TTA：Together, Then Apart双模态fusion_type=coattn，原Together/Apart原型后label_coattn前；保留原Together OT。
可学习：stage_pair_cost、evidence_gate、两侧tanh残差gain；原型仅长token汇总时有梯度。
SlotSPE直接槽路径原型不参与；阶段编码是固定buffer，几何公式、Sinkhorn迭代和平均规则没有可学习参数。
Sinkhorn可微，梯度来自宿主全部原目标；默认evidence_cost_weight=0仍通过边际使用信息量门。
