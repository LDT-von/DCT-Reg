# v3.14 实施与复核计划

更新：2026-09-20。状态：代码候选版；结构检查不等于真实癌种验证。

## 约束

- 不修改 v3.10、v3.11、v3.13 模型，保留历史对照。
- v3.14 不继承、导入任何旧版本模型；自己的 model.py、backbone.py、losses.py 放在同一版本目录。
- 只复用通用 SNN_Block / WSI_Mlp，训练入口保持仓库标准接口。
- 不提交、不推送，不启动真实长训练；当前特征数据路径不可用。

## 执行顺序

1. 对照真实 forward 与训练器，核算 NLL 的求和/平均、删失权重和每个辅助项。
2. 复现塌缩；追踪各损失到 encoder、slot、OT、decoder、event gate 的梯度。
3. 修复跨版本继承、槽路由、无效阶段编码、mask 信息通道和数值问题。
4. 检查缺失模态、训练参考拟合、checkpoint、推理和混合精度。
5. 运行小尺寸、多种子及配置尺寸的合成压力检查；保留失败/中间证据。
6. 提供重构 off / masked / full / hybrid 对照；相同总系数，不叠加两份损失预算。
7. 写出检查报告，区分已修复缺陷、合成证据与尚未完成的临床实验。

## 当前候选目标

\[
L=L_{NLL,\alpha}^{sum}/B+0.10L_{IPCW-rank}
  +0.05L_{slot-NLL,\alpha}+0.02L_{content-distance}
  +0.10r(e)L_{recon},\quad r(e)=\operatorname{clip}((e-2)/5,0,1).
\]

各模态槽位共享本模态的一个 hazard head。槽间差异约束实际内容，不强制同一患者的各槽预测不同风险。
默认重构为 masked：self 与 OT-cross 各占一半。full 是当前骨干上的完整位置重构对照，不是 v3.13 原模型的逐行复刻。

## 验收边界

- 自动测试覆盖前向、反向、数值稳定性、辅助项精确组合、无目标直接输入通道、保存重载与 GPU。
- 合成检查记录 slot cosine、有效秩、槽间标准差、hazard 方差、损失和梯度，不作为 C-index 证据。
- 不承诺零塌缩风险，不把候选权重称为最优。检查结果和后续真实折内消融见 DCT_V314_DEBUG_REPORT.md。
