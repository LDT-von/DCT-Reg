# v3.13 重建与槽监督修复核验

状态：代码修复与合成测试；未启动新的真实患者训练，未产生新的 C-index。

## 正式使用入口

本轮按用户决定保留 WSI 自重建。修正版使用 `configs/dct_v313_full_wsi_repaired.yaml`，其中 `dct_v313_revision: repaired` 明确区分计算版本。旧配置缺省为 `legacy`；原始 v3.11 文件及历史结果不修改。历史 0.7238 不能作为修正版分数。

修正版 Full 的最大系数：IPCW rank 0.10、每槽 NLL 0.05、多样性 0.10；组学自重建 0.05、跨模态重建 0.05、WSI 自重建 0.05。三项重建共同使用 `clip((epoch-2)/5, 0, 1)`，采用 additive 策略。0.15 是系数之和，不代表梯度大小相同。删除一个重建分支时，其余分支保留原系数。

正式训练由用户启动，例如：

```bash
python -m survot_rank.cli train --config configs/dct_v313_full_wsi_repaired.yaml --set results_dir=./results/v313_repaired_full_run1
```

配置沿用 BLCA UNI2-h 数据路径、划分和 30 epoch 预算，启动前按服务器真实路径调整。默认 `legacy_val` 是验证集选择结果；独立测试需要真实 outer-test 划分和明确的评估协议，不能只改标签。

## 修复内容

1. 多样性在每个患者内部按真实 `K(K-1)` 槽对数归一化，不再除以 batch size；先对每对槽计算 hinge，再平均，避免远离群槽掩盖重复槽。显式零权重、零阈值不会被默认值替换。
2. 修正版明确提供的 YAML 参数与 `--set` 都具有覆盖权，`--set` 最后生效。重建权重、比例与 ramp 真正参与计算；legacy 重建加权策略不能混入修正版。
3. WSI 有效 patch 掩码同时用于 MLP 输入、槽提取和自重建。无效值在 MLP 前清零，防止 NaN padding 污染参数梯度；有效性掩码中只有有效 token 参与注意力。显式布尔掩码优先，没有掩码时将原始全零行视为补零。训练和推理都使用这条路径。
4. 每折保存 `v313_implementation_fold*.json`，记录运行时有效系数、ramp、配置来源和 `survot_rank` Python 源码 SHA256。源码哈希用于判断实现是否一致，Git HEAD 变化不能单独证明训练代码变化。外部测试加载 checkpoint 不重复创建训练审计文件。
5. 修正版训练必须使用全新结果根目录，在任何日志写入前拒绝已有目录。审计文件独占创建，保留旧材料。此入口不提供覆盖式恢复或 `only_test` 重跑。
6. 保存各模态槽对的最小距离、重复比例、违反距离阈值比例、完全塌缩患者比例与风险方差。无标签调用清空诊断，避免把旧 batch 统计写进新记录。
7. E048 v1 仍是历史双重建方案，会关闭 WSI 重建；它拒绝修正版参数，避免误把修正版 Full 降成双重建。

## 必须保留的解释边界

- 原始 SlotSPE 已有三项重建；我们的区别应落在原型坐标、运输与预测机制，三项损失的存在不能单独算主要创新。
- 运输计划同时使用病理与组学，因此跨模态重建是配对对齐约束；目标停止梯度不等于只用病理恢复缺失组学。
- 重建目标是编码特征，不是原始 RNA 数值或病理图像。WSI 查询也由停止梯度的目标特征生成，因此属于查询条件下的自重建正则。
- 解码器对槽顺序置换不敏感是集合解码的性质。不能凭低重建误差推断固定槽编号具有固定生物意义；不为制造该结论强行注入编号或随机差异。
- 槽完全相同时，平方距离的梯度仍为零；逐对 hinge 修复了批量依赖和离群补偿，但没有数学上保证摆脱完全塌缩。诊断明确记录这一情况。每槽生存监督是否使表示过度相似，需要训练后证据，不按猜测删除。

## 匹配消融准备

新准备器默认只显示计划，不启动训练、不创建文件：

```bash
python scripts/prepare_v313_repaired_ablation.py --results-root ./results/v313_repaired_ablation_run1
```

需要配置文件时指定一个不存在的输出目录：

```bash
python scripts/prepare_v313_repaired_ablation.py --results-root ./results/v313_repaired_ablation_run1 --out ./prepared_v313_repaired_run1
```

支持 Full、去组学自重建、去跨模态重建、去 WSI 重建、去全部重建、Direct、Independent、去多样性、去每槽 NLL。准备器只生成配置，用户分别启动所选项。所有项沿用相同患者划分、种子、训练预算和重建 ramp；剩余损失系数保持不变。

仅基因、仅病理的 E048 v1 对照保留为历史方案；若要与修正版 Full 比较，需要另行采用与修正版一致的单模态训练目标，不能把旧单模态结果直接搬到新表。
