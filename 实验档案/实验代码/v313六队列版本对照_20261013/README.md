## 使用

在服务器仓库根目录运行，实际源代码须包含独立解码器支持。只打印计划不会训练：

```bash
python '实验档案/实验代码/v313六队列版本对照_20261013/run_three_decoders_six_cancers.py' --results-root '/data1/DCT-Reg/results/v313_three_decoders_six_20261013' --gpu 0
```

用户决定执行后，使用相同命令添加 `--execute`。该开关会开始真实训练；本轮没有调用。
如默认路径不存在，用 `--data-path` 与 `--data-root-dir` 指定实际目录。结果根目录必须全新、为空。
执行前驱动会校验配置、全部源码及六癌种划分文件，执行后冻结 plan.json、base_config.yaml，并保留每折日志/预测/checkpoint。
原版仍以 baseline_frozen.json 为固定参照，不生成原版训练任务。

训练完整结束后，由用户执行 CSV 汇总（只读取现有曲线，不做推理）：

```bash
python '实验档案/实验代码/v313六队列版本对照_20261013/summarize_six_cancers.py' --results-root '/data1/DCT-Reg/results/v313_three_decoders_six_20261013' --output-dir '实验档案/表格图片/v313六队列版本对照_20261013/实测结果_新批次'
```

默认要求每折完整30个epoch，以避免把失败或截断任务当完成。本汇总不覆盖已有目录，不拿缺失值填0。
输出六癌种五折均值/样本标准差、逐折差值、提高折数与曲线哈希；原版已冻结数值精度为公开记录的4位小数。
后续建议画六癌种均值对照与逐折差值两张图；没有新版结果前不制作带分数的效果图。

代码在当前目录；表格、图片与后续实测产物在 ../../表格图片/v313六队列版本对照_20261013/。
这只是准备交付，没有训练结果，也未修改主档、模型、原训练代码或既有成绩。
