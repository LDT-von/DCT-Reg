## 服务器操作

在服务器仓库拉取更新后，先查看 README 与 SERVER_PROMPT。默认运行代码只打印计划；添加 --execute 才开始训练。

plan.preview.json 为便于查看而展开的预览。服务器路径若有变化，以服务器重新生成的计划为准。真实执行时还会核对源码、配置与 split 哈希，并另写运行目录的 plan.json。

原版分数固定复用，不安排重训；新版分数尚为空，完成后由汇总代码生成逐折/均值表。
