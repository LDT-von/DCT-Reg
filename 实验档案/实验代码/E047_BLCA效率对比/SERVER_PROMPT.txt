### 2. 外部方法测量

外部方法使用随机初始化权重测量前向成本。架构参考各论文实现：

#### MCAT (Multi-modal Co-Attention Transformer)
- 架构: WSI 注意力编码 + 通路级omics编码 + co-attention融合
- 参数量: ~20-50M (取决于实现)
- 输入: WSI (B, 2048, 1536) + Omics (B, 765)

#### MOTCat (Multi-Omics Transformer CAT)
- 架构: 多模态transformer，处理WSI和omics token序列
- 参数量: ~30-60M
- 输入: WSI (B, 2048, 1536) + Omics (B, 765)

#### CMTA (Cross-Modal Transformer Aggregation)
- 架构: 跨模态双向注意力
- 参数量: ~25-50M
- 输入: WSI (B, 2048, 1536) + Omics (B, 765)

#### SurvPath
- 架构: 病理-omics融合，token级注意力
- 参数量: ~20-45M
- 输入: WSI (B, 2048, 1536) + Omics (B, 765)

#### PIBD (Pathway Integration with Branch Decoder)
- 架构: 分支解码器分别处理WSI和omics
- 参数量: ~15-40M
- 输入: WSI (B, 2048, 1536) + Omics (B, 765)

#### MMP (Multi-modal Prototype)
- 架构: 原型学习，对WSI和omics分别学习原型
- 参数量: ~10-30M
- 输入: WSI (B, 2048, 1536) + Omics (B, 765)

#### Porpoise
- 架构: 概率化WSI-omics集成
- 参数量: ~20-45M
- 输入: WSI (B, 2048, 1536) + Omics (B, 765)

#### LD-CVAE (Latent Directed CVAE)
- 架构: 潜空间CVAE for生存分析
- 参数量: ~25-50M
- 输入: WSI (B, 2048, 1536) + Omics (B, 765)

### 3. 测量代码模板

```python
import gc
import time
import torch
import numpy as np

def measure_efficiency(model, device, batch_size=1, num_patches=2048, 
                      feature_dim=1536, repeats=30, warmup=5):
    """测量峰值显存和延迟"""
    model = model.to(device)
    model.eval()
    
    # 固定测试输入（与DCT测量一致）
    wsi = torch.randn(batch_size, num_patches, feature_dim, device=device)
    omics = torch.randn(batch_size, 765, device=device)
    
    # 显存测量
    torch.cuda.reset_peak_memory_stats(device)
    with torch.no_grad():
        _ = model(wsi, omics)
    peak_memory_mib = torch.cuda.max_memory_allocated(device) / (1024**2)
    
    # 延迟测量
    with torch.no_grad():
        for _ in range(warmup):
            _ = model(wsi, omics)
    torch.cuda.synchronize()
    
    times = []
    with torch.no_grad():
        for _ in range(repeats):
            start = time.perf_counter()
            _ = model(wsi, omics)
            torch.cuda.synchronize()
            times.append((time.perf_counter() - start) * 1000)
    
    return {
        "peak_memory_mib": float(peak_memory_mib),
        "latency_ms_median": float(np.median(times)),
        "latency_ms_mean": float(np.mean(times)),
        "latency_ms_std": float(np.std(times)),
    }
```

## 注意事项

1. **不要重新训练**：外部方法使用随机初始化权重测量成本
