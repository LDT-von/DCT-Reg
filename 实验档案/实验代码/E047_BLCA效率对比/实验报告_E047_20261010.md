```bash

git clone https://github.com/<author>/MCAT.git

git clone https://github.com/<author>/CMTA.git
git clone https://github.com/<author>/SurvPath.git
git clone https://github.com/<author>/PIBD.git

git clone https://github.com/<author>/Porpoise.git
git clone https://github.com/<author>/LD-CVAE.git

# 2. 下载对应预训练权重（通常在各论文 repo 的 README 说明）

# 3. 在 DCT-Reg 服务器上运行测量脚本
python measure_e047_external_methods.py --all --output results/e047/

# 4. 重新生成图表
python plot_e047_efficiency.py
```
