# DCT v3.13 论文

当前完整中文稿为 `DCT_v313_初稿.md`，Word 交付为 `DCT_v313_初稿.docx`。

本稿保留已有 BLCA/KIRC 的 70 个损失消融记录，采用五折最佳验证 C-index。2026-10-05 审查后，已撤回此前缺少独立运行溯源的 BLCA 控制臂分数、逐折表和提升图。包含完整摘要、方法、结果、讨论、结论、参考文献及逐折结果附录。按作者决定，本次写作不启动新的训练或 outer_test 重跑。

当前图为架构图与损失消融图；旧运输对照图已移至 `history/retracted_transport_controls_20261005/`，禁止引用。`scripts/build_v313_paper.py` 以 Markdown 正文为唯一内容源生成 Word 和图表；`scripts/export_v313_paper_pdf.ps1` 调用本机 Word 生成内部排版检查 PDF。

新版主架构图采用四分区英文排版：语义槽编码、阶段多几何运输、生存预测、运输感知重建。`figures/v313_architecture.svg` 为可编辑矢量图，`.pdf` 为嵌入字体的矢量版本，`.png` 为 4880 × 3008 像素版本；`_preview.png` 用于快速预览。`scripts/draw_v313_architecture.py` 可独立重画，论文构建也会调用此脚本，避免覆盖成旧版。所有纹理、矩阵和曲线均为示意，不代表实测数据。

此前 `DCT_唯一初稿.*` 主要对应 v3.10，其正文与数据不作为当前 v3.13 的实验依据。

损失表和方差统计已依据记录折值重算。Direct 与 Independent 的历史汇总暂不进入当前数值结论；单支重建历史有效系数为 0.025，Full 每支系数为 0.05。论文据此保留平均提升，并明确比较范围。

当前结论仅支持完整联合训练配方在已有损失消融中的平均收益，尚不主张已证明运输对齐或学习联合耦合的独立收益。Stage B 审查文本未提供四组完整分数，本稿不补造外部比较。
