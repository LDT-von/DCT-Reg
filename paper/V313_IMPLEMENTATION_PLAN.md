状态：方案已细化，实验代码尚未按本计划实现；本次没有启动训练、推理或数据处理。用户已选择同时交付开发比较与独立测试协议，以及中文 Markdown 和 Word 初稿。

## 一 目标与范围

本阶段集中交付四类实验：损失消融、原版 SlotSPE 同协议比较、普通跨模态重建、独立耦合。首轮默认 BLCA、KIRC，fold 0–4，seed 3。癌种、fold 和 seed 可通过参数选择，扩展队列支持 HNSC、LUSC、SKCM。

阶段共享、单几何、去原型、其他公开模型、外部验证及大规模超参搜索不放入本轮执行矩阵。它们仍是后续研究选项，不能写成已经完成的实验。

交付物：

- 新实验配置、模型对照开关、SlotSPE 适配器及两套评估流程。
- 默认仅打印计划的统一调度入口，结果核验与汇总工具。
- CPU 合成数据测试、Linux 服务器预检与运行说明。
- `DCT_v313_初稿.md` 与 `DCT_v313_初稿.docx`，对应框架图和可编辑公式。

正式服务器训练由用户启动。源代码和配方更新不接管现有调度进程，不覆盖现有结果。

## 二 实验矩阵与实际目标

### 2.1 损失消融

新配方标识使用 `v313_paper_v1`。下表重建系数均指 ramp 满后的有效系数。

| 实验臂 | 实际目标 |
|---|---|
| Exp0 | NLL |
| Exp1 | NLL + 0.10 IPCW rank |
| Exp2 | Exp1 + 0.05 per-slot NLL |
| Exp3 | Exp2 + 0.10 diversity |
| Exp4 | Exp3 + 0.05 self reconstruction |
| Exp5 | Exp3 + 0.05 cross reconstruction |
| Exp6 | Exp3 + 0.05 self + 0.05 cross |

Exp0 仍采用 DCT 主干。Exp0→Exp3 是按固定顺序加项，不能据此宣称每项在完整目标中的独立贡献。

新配方修复单支重建二次降权：关闭一支只将该支有效系数置零，另一支保持 0.05。所有新配置设 `scale=1`；此前 `scale=2` 仅是 93d8314 旧配方的临时补偿，不能复制进新配置。

保留旧入口的默认配方行为。新增 `dct_v313_recon_weighting=legacy|per_branch`，旧入口默认 `legacy`，论文矩阵显式选 `per_branch`。由统一权重解析结果同时驱动总损失、日志和运行记录，禁止日志宣称关闭而组合器仍乘类常量。

重建 ramp 继续使用 `clip((epoch-2)/5,0,1)`。测试同时检查 ramp 未启动、爬升中及满权重阶段。

### 2.2 SlotSPE 原版适配与公平性

仓库 `third_party/SlotSPE` 的模型、slot attention、transformer、编码器和损失文件已与用户指定原目录比较；排除换行差异后源码一致。使用这些源码封装 `slotspe_reference`，隔离模块命名空间，避免误导入 DCT 兼容运行时中的同名工具。

保留原版计算图、Top-K 解码和原版辅助重建/模态预测损失。统一数据入口、终点、分箱、划分、特征、评价与训练轮数，不向原版加入 DCT 正则。

为避免将 DCT 的训练超参数强加给基线，提供两个预先确定的 SlotSPE 配方，分别报告：

| 参数 | DCT 各臂 | SlotSPE matched | SlotSPE native |
|---|---:|---:|---:|
| epochs | 30 | 30 | 30 |
| batch | 8 | 8 | 32 |
| optimizer | AdamW | AdamW | Adam |
| learning rate | 0.0005 | 0.0005 | 0.0005 |
| weight decay | 0.0005 | 0.0005 | 0.001 |
| alpha_surv | 0.15 | 0.15 | 0.5 |
| slot iterations | 3 | 10 | 10 |
| 原版 lambda_recon_loss | 不适用 | 0.01 | 0.01 |

两种 SlotSPE 配方的模态槽数均为 8+8，保留原版其余结构设置。`native` 指原生优化/损失配方在统一数据评估协议下的复现，不指复制原论文的全部数据处理流程。

预先指定 native 为主要原版配方，matched 为补充公平性对照；不根据测试分数逐折挑选两者的最大值。共同输入为 UNI2-h 1536 维、2048 patches、Pathways/combine、DSS、四个离散时间箱。

适配器验收必须在相同参数、输入和随机状态下比较原版与适配版 logits 和辅助损失；不以函数能导入替代行为核对。

### 2.3 普通重建对照

新增 `dct_v313_cross_mode=transport|direct`，默认 `transport`。

- transport：按事实 OT 运输 WSI slots，随后输入现有通路查询解码器。
- direct：直接将未运输的 WSI slots 输入同一个解码器。

direct 臂保留完整预测 OT、self 重建、全部其他损失、同一解码器与同一重建系数。两种模式不新增不同容量的头，不改重建目标与归一化方式。

其比较结论限定为“在同一 DCT 主干上，使用运输后表征的增量”。cross 支路的 OT 同时依赖两种模态，因此不据此声称缺失组学填补或原始基因表达恢复。

### 2.4 独立耦合对照

新增 `dct_v313_plan_mode=learned|independent`，默认 `learned`。

independent 在每个患者、阶段和几何位置使用相同边际的 `T=abᵀ`，替换训练及评估中的主预测计划和 cross 重建计划。保留槽表示、边际生成器和风险读取器，重新训练。

不得用 `1/(K_w K_o)` 替代非均匀边际的独立耦合；不得只在训练或审计函数里生效而遗漏 eval 路径。独立耦合仍有可学习边际，不标为“所有跨模态信息均已删除”。

### 2.5 任务数量

七个损失臂 + 两个 SlotSPE 配方 + direct 重建 + independent 耦合 = **11 个实验臂**。

每协议两癌种五折为 **110 个任务**；两套全部从头运行上限 **220 个任务**。相比上一版增加的 20 个任务来自 SlotSPE 原生训练配方对照。调度器必须允许按协议和实验臂筛选，不要求一次启动全部任务。

历史任务只有在代码行为、配置、有效权重、数据/划分及选模口径可核验时才能引用。旧 Exp4/5 的 0.025 记录保留为低权重历史结果，不自动改标签为 0.05。

## 三 数据与两套评估协议

### 3.1 共同的数据约束

- 患者级划分；同一患者全部切片位于同一子集。记录实际入组、排除原因、事件数和删失比例。
- 不静默改变各方法的数据覆盖。预检发现缺失或损坏的 WSI/omics 时，列出患者 ID 并使对应任务失败；共同排除患者必须形成新的、所有臂一致的数据清单。
- 新实验的数据适配层显式携带 `case_id`。预测结果按实际患者 ID 关联，禁止依赖过滤前的行号猜测 ID。
- 当前非训练 patch 选择已是确定性等间隔采样，保留这一行为，并确认新 test split 走相同分支。共享相同输入排序、patch 上限和填充规则。
- 记录数据采样随机数设置；同一组 DCT 消融使用一致的数据顺序和采样策略。评价不能因模型不同而切换到不同患者或 patch 集。

### 3.2 legacy_val

使用原五折 train/val。根据每折 val C-index 选最佳 epoch，明确标识为开发比较。该协议用于衔接已有实验，不描述为独立测试。

### 3.3 outer_test

1. 原五折 val 固定为外层 test，原 train 内分出 20% 作 inner val。
2. 按事件/删失状态分层，固定 split seed 3；排序患者 ID 后生成划分并持久化。所有模型与模型 seed 复用同一划分。
3. 时间分箱、可拟合预处理、删失参考及风险锚点只使用 inner train。新流程推迟 factory 的全队列分箱，不能先拟合全数据再将其遗留状态带入模型。
4. 内验证决定 checkpoint；C-index 相同时保留较早 epoch。没有可用选择指标时任务标为失败，不改用外层 test 选模型。
5. 不在选模后使用外层 train 全量重新拟合；直接恢复选定的 inner-train checkpoint，对 outer test 评价一次。
6. 若事件不足以分层或形成规定时间箱，输出具体原因，不回退到全数据拟合。

“独立”指测试患者不参与本次训练和选模。既往在这些 TCGA 队列上的方法开发历史应在论文中披露，不称为全新盲测或外部验证。

### 3.4 checkpoint 重放

当前 DCT 通过 epoch 计算 Sinkhorn epsilon，模型权重文件未必包含所有运行条件。新结果包需保存并恢复：

- 选定 epoch、实际 epsilon、模型配置、模型状态及推理模式。
- 标签分箱、阶段边界、训练删失参考，以及运行所需的非参数状态。
- 数据清单、eval patch 规则与可重放的随机状态/随机种子。

重载后的风险预测应在规定数值容差内重现选中 checkpoint 的预测。禁止重载后默认使用 epoch 0 或最后训练轮次的 OT 配置。

## 四 接口 调度 汇总与验证

### 4.1 接口

在现有配置链路中增加以下字段：

- `evaluation_protocol=legacy_val|outer_test`
- `inner_val_fraction=0.20`、`split_seed=3`
- `dct_v313_recon_weighting=legacy|per_branch`
- `dct_v313_cross_mode=transport|direct`
- `dct_v313_plan_mode=learned|independent`

统一调度入口支持协议、癌种、实验臂、fold、seed、GPU、每 GPU 并发数和显式执行开关。默认仅输出任务清单；并发默认每 GPU 一个训练子进程，允许用户提高。

### 4.2 任务状态与结果隔离

- 新实验目录含配方版本、协议、实验臂、癌种、fold、seed，避免碰撞历史目录。
- 每个任务输出模型构造后的有效配置与权重，而不只保存原始 YAML。
- 记录 running/completed/failed/interrupted、预期训练轮数、完成轮数和结束原因。
- 子进程退出成功、必要结果齐全、配置签名匹配且终止原因有效，才允许标为 completed 或跳过。
- 旧日志的 `best cindex` 文本不是完成证明；中断留下的 checkpoint 也不是完整任务证明。
- GPU 分配在子进程导入 Torch 前生效，并记录物理 GPU 与进程可见设备，避免两个队列实际抢同一张卡。
- 真实数据短跑使用独立 smoke 配置和目录；其完成记录不能被正式任务复用。

### 4.3 指标与结果汇总

以同一选定 checkpoint 计算 C-index、IPCW C-index、IBS 和 iAUC，不为各指标分别挑最高 epoch。相同癌种、fold、协议的比较使用相同患者与评价时间网格。

确认生存概率方向、单调性、时间箱到评价时点的映射以及删失参考支持范围。时间范围规则在评价前固定，不按某模型表现选择。不可计算的指标显示缺失及原因，不能补零或静默过滤患者。

汇总保存各折结果、均值与标准差、有效折数和关键成对差值；不同癌种与不同协议分表。不把五折或两癌种当作大量独立重复，不直接混合跨癌种风险分数计算一个 C-index。

### 4.4 验收测试

| 检查 | 验收标准 |
|---|---|
| 配置到实际目标 | CLI 覆盖经过完整解析与构造后仍生效；七臂有效系数与表一致 |
| 单支重建 | 新配方保留支路为 0.05；关闭支路系数和梯度贡献为零；旧配方保持历史行为 |
| 对照模式 | direct 仅改变重建 memory；independent 同时覆盖训练与 eval 的主预测和重建 |
| 独立计划 | 非负、总质量为一，行/列和等于对应边际 |
| 梯度路径 | transport cross 对运输路径保留预期梯度；direct cross 不通过运输计划传播 |
| 原版适配 | 相同随机状态下，适配前后 logits、辅助损失及其归一化一致 |
| 数据身份 | train/val/test 无患者重叠；损坏样本触发带 ID 的错误；输出 ID 与预期清单一一对应 |
| 泄漏检查 | 修改 test 标签不能改变训练分箱、参考或选择的 checkpoint |
| 重载一致性 | 保存后重新构建模型及上下文，复现选定 checkpoint 的风险输出 |
| 任务调度 | 默认不训练；GPU 映射正确；失败/中断不会被跳过为完成 |
| 汇总 | 不混合协议；缺折与指标失败可见；不伪造缺失数据 |

实施期执行有针对性的 CPU 合成数据测试。真实数据预检、短跑、GPU 训练和推理由用户按交付命令启动。
